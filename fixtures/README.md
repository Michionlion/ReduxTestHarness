# Test fixtures

Place developer-owned KSP2 save fixtures here. For the included smoke test, add:

```text
fixtures/rendering/kerbin-orbit.json
```

The save should enter flight with a controllable vessel named `Render Test Vehicle` in Kerbin orbit above 70 km.

Save files are not included because they may contain user/campaign data. Treat fixture saves as immutable test inputs and version them only after reviewing their contents.
